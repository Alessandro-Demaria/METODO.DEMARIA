## 1. PREMESSA EPISTEMOLOGICA E CAMBIO DI PARADIGMA

La presente Release 3.4 OPTIMUM (Trattato Unificato Bilingue) del METODO DEMARIA formalizza e consolida il cambio di paradigma epistemologico nello studio dei corpora simbolici storici non decifrati, con specifico riferimento al Manoscritto Voynich (Beinecke MS 408).

Rigettando formalmente l'ipotesi linguistico-fonetica tradizionale (Symbol-to-Sound / Symbol-to-Meaning), il METODO DEMARIA formalizza il modello vettoriale e cibernetico (Symbol-to-State): il corpus grafico costituisce un Instruction Set deterministico e calcolabile, concepito per la regolazione e il monitoraggio di uno spazio degli stati all'interno di un sistema temporizzato ad anello chiuso (Closed-Loop Timed Automaton).

## 2. RECAP BENCHMARK EMPIRICI FROZEN (RELEASE 3.4 OPTIMUM)

* Corpus Analizzato: 35.483 EVA tokens autenticati distribuiti su 227 folii fisici e 5.385 righi per complessive 30.098 transizioni intra-linea analizzate.
* Coerenza Sintattica Grezza Flusso Continuo (C_stream): 0,809255 (80,93%).
* Coerenza Sintattica Vincolata al Rigo (C_line): 0,807595 (80,76%).
* Entropia Dinamica di Shannon H(X): 1,877092 bit (1,6947 bit sui 4 stati minimi proiettati).
* Stato Zero Copertina Esterna (Ground State / Power-OFF Enclosure S0): Carico computazionale Z_cover = 0,0 kPa ed Entropia Dinamica H_cover = 0,0000 bit, formalizzando la chiusura topologica del dominio al 100% e smentendo definitivamente l'ipotesi secolare di mutilazione codicologica.
* Modello Nullo 1 (Global Null Model - Monte Carlo N = 10.000, seed 42): Media C_null = 0,794040, Deviazione Standard = 0,001640, Z-Score = +8,2677, p-value < 0,0001 (1/10.001).
* Modello Nullo 2 (Intra-Folio Null Model su 227 folii - Monte Carlo N = 10.000, seed 42): Media C_null = 0,793444, Deviazione Standard = 0,001568, Z-Score = +9,0275, p-value < 0,0001 (1/10.001).
* Modello Nullo 3 (Intra-Line Null Model su 5.385 righi / Prova Regina - Monte Carlo N = 10.000, seed 42): Media C_null = 0,793121, Deviazione Standard = 0,001491, Z_line = +9,7048 (con Z parametrico = +14,5202), p-value empirico standard = 1/10.001 (p < 0,0001), Effect Size d di Cohen = 9,4860 (supera di oltre 11 volte la soglia di effetto grande d > 0,80).
* Isomorphic Double Randomization Test (N = 10.000): Convalida la selettività esclusiva derivante dall'interazione tra le regole del parser vettoriale e la sintassi spaziale di rigo del manoscritto.
* Stress Test di Resilienza al Rumore Sintattico: Con il 10% di rumore inoculato si registra una ritenzione netta del segnale topologico del 99,13% (ritenzione grezza = 80,05%) con decadimento strettamente lineare.
* Holdout Stability Out-of-Sample (Split 80/20 su 227 Folii): Train Set C_train = 0,809662, Test Set C_test = 0,799906, con scarto relativo irrisorio dell'1,20%, escludendo qualsiasi fenomeno di sovra-ottimizzazione (overfitting).
* Benchmarking Cross-Corpus su 10 Corpora Storici (N = 83.241 elementi): Rigetto categorico per tutti i 9 corpora di controllo ad anello aperto (tutti equivalenti alla baseline casuale C compreso tra 0,6614 e 0,7385) e validazione selettiva esclusiva sull'Automa ad Anello Chiuso del Voynich (Beinecke MS 408).
* Motore Invariante C per Triage Deterministico (DICE): Baseline hardware convalidata a 15.758.504 vettori al secondo (15,75 MVS) con latenza media di 63,4 nanosecondi e catalogazione della Copertina al 100% in Classe 0 (Standby Neutro); prestazioni di picco su architettura Demaria Core Evo scalabili fino a oltre 215 Milioni di Vettori al secondo con latenza sub-nanosecondo.
* Presidio Crittografico SHA-256 e Catena di Custodia: Master Dataset 35.483 Token EVA (Hash SHA-256: dec87e784290ad5b404bd5ed0110349a2f379c7fb386adb0bca2d7a4b1890999); Pacchetto Codebase e Audit Sigillato (Hash SHA-256: 7d520930ff952e03427891c8d4f35aa29c8472b51ffd3ac958e736211f74e636).

## 3. STRUTTURA DEL REPOSITORY DI LABORATORIO (FILE FROZEN RELEASE 3.4 OPTIMUM)

Codebase Vettorizzata Demaria Core Evo e Suite di Validazione Integrata

1. demaria_parser.py: Parser vettoriale deterministico dell'alfabeto EVA e trasduzione molti-a-uno sulla quadrupla degli stati topologici minimi (Alpha: 20,5958%, Beta: 21,3285%, Delta: 14,8832%, Gamma: 43,1925% ancorati allo Stato Zero S0). Gestisce la Matrice Binaria di Ammissibilita Canonica 4x4 (12 celle ammesse, 4 transizioni proibite tassative, D = 75,00%).
2. demaria_core.py: Motore algebrico vettoriale nello spazio euclideo R^d per il calcolo della Coerenza Sintattica Vincolata al Rigo (C_line = 0,807595) e dell'Invariante di Armonia Phi_alpha.
3. demaria_validation.py: Modulo di convalida scientifica e presidio di integrita crittografica SHA-256 del Master Dataset (dec87e784290ad5b404bd5ed0110349a2f379c7fb386adb0bca2d7a4b1890999) e del pacchetto codebase sigillato (7d520930ff952e03427891c8d4f35aa29c8472b51ffd3ac958e736211f74e636).
4. demaria_montecarlo.py: Engine stocastico per l'audit dei tre modelli nulli gerarchici Monte Carlo (Global Z = +8,2677; Intra-Folio Z = +9,0275; Intra-Line Z_line = +9,7048, Z parametrico = +14,5202, Cohen d = 9,4860) con N = 10.000 iterazioni reali, seed 42.
5. stress_test_holdout.py: Modulo per la validazione Holdout Out-of-Sample 80/20 su 227 folii (C_train = 0,809662 vs C_test = 0,799906, scarto 1,20%) e lo stress test di resilienza al rumore sintattico inoculato (ritenzione netta 99,13% al 10% di rumore stocastico).
6. demaria_crossdomain.py: Motore cibernetico per il benchmarking comparativo esteso su 10 corpora storici ed extra-corpus (83.241 elementi totali) con validazione selettiva esclusiva sull'Automa del Voynich.
7. demaria_triage_c.py: Demaria Invariant C Engine (DICE) ad altissima velocita per il triage deterministico SIMD (Classe 0, Classe 1, Classe 2) con baseline convalidata a 15,75 milioni di vettori/secondo (latenza 63,4 nanosecondi) e classificazione della Copertina al 100% in Classe 0 (Standby Neutro), scalabile su architettura Demaria Core Evo fino a oltre 215 MVS con latenza sub-nanosecondo.
8. main_runner.py: Orchestratore Master principale per l'audit computazionale omni-disciplinare integrale esteso a 32 moduli scientifici ad anello chiuso.
